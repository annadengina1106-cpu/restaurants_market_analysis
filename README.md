# Анализ рынка общественного питания Москвы

Исследовательский анализ данных о заведениях общественного питания Москвы с подготовкой рекомендаций по открытию нового заведения.

**Автор:** Деньгина Анна
**Дата:** 15.09.2026

---

## Цель проекта

Провести исследовательский анализ рынка общественного питания Москвы и на основе данных подготовить рекомендации по открытию нового заведения общественного питания.

---

## Данные

- `rest_info.csv` — 8406 строк, 9 столбцов: название, адрес, административный округ, категория, статус сетевого заведения, часы работы, рейтинг, количество посадочных мест.
- `rest_price.csv` — 4058 строк, 5 столбцов: ценовая категория, средний чек, средняя стоимость чашки кофе.

Датасеты объединены по столбцу `id` в единый датафрейм (8406 строк, 13 столбцов).

---

## Содержание проекта

1. Загрузка данных и знакомство с ними
2. Предобработка данных (типы данных, пропуски, дубликаты, новый признак `is_24_7`)
3. Исследовательский анализ данных — 8 исследовательских задач:
   - Распределение заведений по категориям
   - Распределение по округам Москвы и структура Центрального округа
   - Соотношение сетевых и несетевых заведений
   - Анализ количества посадочных мест
   - Анализ рейтингов заведений
   - Корреляция рейтинга с другими признаками
   - Топ-15 популярных сетей
   - Средний чек по округам
4. Итоговый вывод и рекомендации

## Основные результаты

- Рынок сконцентрирован по категориям: кафе и рестораны занимают более половины всех точек (52.58%).
- Бизнес тяготеет к центру: Центральный округ — 26.68% рынка, средний чек там на 351₽ выше, чем в остальных округах (1191₽ против 839.82₽).
- Сетевой формат преобладает не везде: в среднем несетевых заведений больше (61.88%), но в булочных, пиццериях и кофейнях доминируют сети (50–61%).
- Рейтинги стабильно высокие (медиана 4.3) и слабо различаются между категориями (разброс 0.34 балла); из проверенных факторов сильнее всего с рейтингом связана ценовая категория (корреляция 0.22).
- В данных о топ-сетях обнаружено ограничение: часть записей — это обобщённые названия по типу заведения, а не реальные бренды.

## Как запустить проект

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/annadengina1106-cpu/restaurants_market_analysis.git
   ```

2. Установите необходимые библиотеки:

   ```bash
   pip install pandas matplotlib seaborn phik jupyter
   ```

3. Откройте ноутбук:

   ```bash
   jupyter notebook "Проект_Рынок_общественного_питания_Москвы.ipynb"
   ```

   Для полного воспроизведения расчётов потребуются исходные файлы `rest_info.csv` и `rest_price.csv` в папке `/datasets/` — они являются учебными и не включены в этот репозиторий.
